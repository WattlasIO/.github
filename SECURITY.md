# Security & Data Corrections

## Reporting security issues

If you find a security vulnerability in any public repository under `WattlasIO` or on `wattlas.io`, please report it privately to **hello@wattlas.io** rather than opening a public issue. Include reproduction steps and the affected URL or repository path.

## Data corrections or removal requests

For factual corrections or removal requests related to public records displayed on `wattlas.io`, use [wattlas.io/removal](https://wattlas.io/removal) or email **hello@wattlas.io**.
